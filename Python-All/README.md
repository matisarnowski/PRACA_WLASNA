# Projekty w Języku Python

Ten katalog zawiera zbiór moich różnorodnych projektów i skryptów napisanych w języku Python. Eksploruję tu różne aspekty tego języka, od podstawowych skryptów po bardziej zaawansowane zastosowania.

## Kategorie projektów:

* **Skrypty Automatyzujące:** Narzędzia ułatwiające codzienne zadania, operacje na plikach, przetwarzanie tekstu.
* **Aplikacje GUI:** Proste aplikacje z graficznym interfejsem użytkownika (np. z wykorzystaniem Tkinter).
* **Projekty związane z Danymi:** Ćwiczenia z bibliotekami takimi jak NumPy, Matplotlib, praca z plikami CSV, JSON, Excel (openpyxl) – podstawy analizy i wizualizacji danych.
* **Web Development (Flask/Django):** Podstawowe projekty i ćwiczenia z wykorzystaniem frameworków Flask i Django.
* **Algorytmika i Rozwiązywanie Problemów:** Implementacje różnych algorytmów i struktur danych.
* **Programowanie Obiektowe (OOP):** Przykłady i ćwiczenia ilustrujące zasady OOP w Pythonie.

Staram się tu rozwijać wszechstronne umiejętności w języku Python i poznawać jego bogate możliwości.
