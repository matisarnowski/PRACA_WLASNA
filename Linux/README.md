# Linux - Administracja i Skrypty

Ten folder poświęcony jest systemowi Linux. Znajdują się tu moje notatki, skrypty oraz materiały związane z nauką administracji tym systemem operacyjnym.

## Zawartość:

* Skrypty powłoki (Bash) automatyzujące różne zadania.
* Notatki z konfiguracji systemu i usług.
* Materiały z książek i kursów dotyczących administracji Linuksem (np. konfiguracja sieci, zarządzanie użytkownikami, praca z terminalem).
* Przykłady konfiguracji dla specyficznych dystrybucji (np. Fedora, Ubuntu, czy GhostBSD, z którym obecnie eksperymentuję).

Moim celem jest pogłębianie wiedzy na temat systemów Linux i praktyczne wykorzystanie zdobytych umiejętności.
